# 🍳 우리집 식탁

이번 주 식단 · 냉장고 재고 · 장볼 목록 · 가계부 · 장보기 요약을 한 화면에서 보는 모바일 웹앱입니다.
파일 하나(`index.html`)로 끝나는 정적 웹앱이라 GitHub Pages에 그대로 올리면 됩니다.

## 쓰는 법
1. 아이폰 사파리에서 주소를 엽니다.
2. 공유 → **홈 화면에 추가**를 누르면 앱처럼 아이콘이 생깁니다.
3. 기록은 그 브라우저의 `localStorage`(키 `sohee_table_v2`)에만 저장돼요. 새로고침해도 그대로 남습니다.

## 상단 요약 카드
- 첫째 줄 — **{이번 달}월 식비**(가계부에서 이번 달 `결제액 − 할인`만 합산, 달이 바뀌면 0원부터) · **남은 재고**(보유 중인 재료 수) · **이번 주 식단**(이번 주 끼니 수)
- 둘째 줄 — **남은 재고 가치**(냉장고에 남은 재료의 현재 금액, 상비품 제외 · 소진 처리하면 바로 줄어듦) · **소진비용** · **끼니당 식대(소진 N끼)**

## 탭
- **주간 식단** — 이번 주 진행률, 요일별 끼니 카드, 체크로 완료/미완료, 연필로 수정·삭제
- **냉장고 재고** — 검색·카테고리 칩, `★ 즐겨찾기 (N)` 필터 칩, 보유 중/소진 토글, 즐겨찾기, `주문내역/영수증 붙여넣기`로 여러 품목 한 번에 담기. ★을 켠 품목은 목록 맨 위로 정렬됩니다.
- **즐겨찾기** — ★ 켠 품목만 모아 보기(재고 관리와 같은 카드). 즐겨찾기가 비어 있으면 담는 방법을 안내합니다.
- **장볼 목록** — 체크한 품목을 `냉장고로 이동`(가계부에도 기록)
- **가계부** — 결제 건별 식비 기록, 할인·쿠폰 금액 반영, 상단에 `N월 식비`(이번 달 합계)와 이번 주 합계
- **장보기 요약** — 총 구매비용·소진비용·남은 재고 가치·끼니당 식대, 카테고리별 지출 비율, JSON 백업/불러오기

## 즐겨찾기
`★`을 누르면 그 품목이 재고 목록 맨 위로 올라오고, 하단 `즐겨찾기` 탭과 재고 화면의 `★ 즐겨찾기 (N)` 칩에서 즐겨찾기만 모아 볼 수 있어요.

## 상태 표기
일반 식료품과 상비품 모두 보유 상태는 **`보유 중`** 하나로 통일되어 있어요(떨어졌을 때는 일반은 `소진`, 상비품은 `떨어짐`).

## 상비품
쌀·김·소금·간장·조미료·커피·콤부차처럼 개수 세기 번거로운 것은 `상비품`으로 표시하면
`보유 중 / 떨어짐` 한 번으로만 관리하고, **소진비용과 끼니당 식대 계산에서는 빠집니다**(결제 금액은 가계부에 남습니다).
`떨어짐`으로 바꾸면 장볼 목록에 자동으로 담깁니다.

## GitHub Pages 배포
```bash
# 저장소 만들고 이 폴더 내용을 올리기 (index.html이 저장소 루트에 오도록)
git init
git add index.html README.md
git commit -m "우리집 식탁 웹앱"
git branch -M main
git remote add origin https://github.com/<아이디>/<저장소>.git
git push -u origin main
```
GitHub 저장소 → Settings → Pages → Source `Deploy from a branch` → Branch `main` / `/ (root)` → Save.
잠시 뒤 `https://<아이디>.github.io/<저장소>/` 에서 열립니다.
